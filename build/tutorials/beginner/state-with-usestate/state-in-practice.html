State in Practice

Sharing state between components and building a working counter.

Two sibling components cannot see each other's state. When both need the same value, move it up to their closest common parent. This is called lifting state up.

Where should a piece of state live?

  1. Find every component that reads the value.
  2. Find their closest common parent.
  3. Put the state there, and pass the value and an updater down.

Note

If the common parent is many levels up, you are hitting prop drilling. Context or a state library solves that, and both are covered in the intermediate track.
